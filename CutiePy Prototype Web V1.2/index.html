What is Python?

Python is a high-level, general-purpose programming language created by Guido van Rossum and first released in 1991. This design goal shows up directly in Python's syntax: it uses indentation (whitespace) to define code blocks rather than braces or keywords, which forces a clean, consistent visual structure across all Python code, regardless of who wrote it.

Python is dynamically typed and interpreted, meaning variables don't require explicit type declarations, and code is executed line-by-line by an interpreter rather than compiled ahead of time into machine code.
