Python resources

A quick reference for your next line of code.

Review the building blocks of Python before you return to a lesson or challenge.

Basics

Variables

A variable stores a value under a readable name.

name = "CutiePy"
print(name)

Decisions

Conditions

Use conditions when a program needs to choose what happens next.

if score >= 60:
    print("Pass")

Repetition

Loops

Loops repeat a block of code over a range or collection.

for number in range(3):
    print(number)

Reuse

Functions

Functions give a reusable name to a block of logic.

def greet(name):
    return "Hi " + name

Collections

Lists and dictionaries

Lists keep ordered values; dictionaries pair readable keys with values.

colors = ["red", "blue"]
user = {"name": "Ada"}

Debugging

Common errors

  • SyntaxError means the code structure is invalid.
  • NameError means a name is missing or misspelled.
  • TypeError means incompatible data types were used.
