Help center

Questions students ask.

Find a quick answer, then jump back into your learning path.

How do I start learning?

Open Lessons from the main navigation and select a module. Each lesson includes an explanation, example code, and a practice challenge.

How do I complete a challenge?

Open a challenge, read the task and hint, write your Python code, then select Submit Answer. Questions unlock in order as you complete them.

How is my progress saved?

This prototype saves progress in your browser using local storage. Progress is tied to the email used for your CutiePy account on that browser.

What should I do when my code has an error?

Read the error type first, check spelling and indentation, then use the hint or ask Chikawa. The Resources page includes a short error reference.

Can I use the AI Tutor?

Yes. Open Chikawa from the tutor button in the learning workspace. The prototype includes local Python guidance and can use an optional configured AI connection.

Is CutiePy a full Python interpreter?

CutiePy is an educational prototype with a limited browser-based interpreter. Use the examples provided in each lesson and test production Python in a full Python environment.
